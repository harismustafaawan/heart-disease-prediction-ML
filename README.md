# Heart Disease Prediction System

A machine learning-based desktop application built with Python and Tkinter to predict heart disease using medical attributes.

## Features
- Load and preview CSV datasets
- Automated preprocessing (missing value handling, encoding, scaling)
- Trains and compares 3 ML models: Logistic Regression, Random Forest, SVM
- Selects best model based on F1-score
- Real-time prediction through GUI input
- Saves trained model, scaler, and feature names for reuse

## Technologies Used
- Python
- Tkinter (GUI)
- Scikit-Learn
- Pandas, NumPy
- Pickle (model saving)

## Workflow
1. Dataset Loading
2. Data Preprocessing
3. Model Training & Evaluation
4. Real-time Prediction
5. Result Interpretation
